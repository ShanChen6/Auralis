# Auralis Audio AI

Dịch vụ Hybrid TTS và hậu kỳ Radio của Auralis (FastAPI). README này dùng làm cấu hình cho Hugging Face Space.

Các biến cần đặt trong **Settings → Variables and secrets** của Space:
`AUDIO_AI_API_KEY`, `R2_ACCOUNT_ID`, `R2_ACCESS_KEY_ID`, `R2_SECRET_ACCESS_KEY`, `R2_BUCKET`, `R2_PUBLIC_URL`.
